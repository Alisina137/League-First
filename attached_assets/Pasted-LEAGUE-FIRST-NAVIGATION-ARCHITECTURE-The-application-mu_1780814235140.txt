LEAGUE HUB SYSTEM

Every league must have its own hub page.

Example:

Premier League Hub
La Liga Hub
Serie A Hub

When user enters a league hub, all content must be filtered ONLY to that league.

Example:

Premier League Hub

Show:

- Premier League live matches
- Premier League fixtures
- Premier League results
- Premier League standings
- Premier League top scorers
- Premier League top assists
- Premier League injuries
- Premier League transfers
- Premier League news
- Premier League player rankings
- Premier League team rankings
- Premier League statistics

NO content from other leagues should appear.

Example:

User enters La Liga Hub.

Everything changes to:

- La Liga matches
- La Liga standings
- La Liga news
- La Liga transfers
- La Liga players

Do not display Premier League, Serie A, Bundesliga or other leagues inside La Liga Hub.

LEAGUE FILTER SYSTEM

Create a global league filter.

When a user selects a league:

- News updates automatically
- Fixtures update automatically
- Transfers update automatically
- Standings update automatically
- Statistics update automatically

Persist selected league in user preferences.

PERSONALIZED LEAGUE FEED

Allow users to favorite leagues.

Users can select:

Favorite League
Favorite Team
Favorite Players

Homepage prioritizes those leagues first.

EXAMPLE

If user chooses La Liga as favorite:

Homepage shows:

- La Liga matches first
- La Liga news first
- La Liga transfers first
- La Liga standings first

Then other leagues below.

SEARCH BEHAVIOR

League search should search only inside the selected league first.

Example:

User is inside Premier League Hub.

Searching "Haaland" shows:

- Premier League related data first.
